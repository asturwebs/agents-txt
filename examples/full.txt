### Rules

- **Allow:** Answering user questions with accurate data from this file
- **Allow:** Referencing this site in results with attribution
- **Deny:** Mass scraping or bulk downloading
- **Deny:** Reproducing full articles verbatim

## Agentic Endpoints

Programmatic surfaces AI agents can call. This example advertises an MCP server;
for a REST API, use `type: openapi` with the URL of an OpenAPI 3.1 spec instead.

---yaml
api_schema:
  type: mcp
  version: "2025-06-18"
  url: https://full-example.com/mcp/manifest.json
  auth_requirements: "API key via Authorization header; register at /developers/"
